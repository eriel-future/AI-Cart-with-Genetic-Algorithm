# AI-Car-with-Genetic-Algorithm

Artificial Intelligence project using a **Genetic Algorithm** to train cars to navigate different race tracks.

The project was developed using **JavaScript, HTML, and CSS**. JavaScript is responsible for the game logic, car behavior, Genetic Algorithm, and training process, while HTML structures the application and CSS handles the visual styling and layout.

The goal of the project is to make the cars learn, through multiple generations, how to navigate the tracks more effectively.

At the end, the best car should be able to complete a full test by successfully passing through all **3 different tracks**.

## How It Works

The project uses a **Genetic Algorithm** to automatically evolve the cars.

Initially, multiple cars are placed on a track to test their performance. Each car has characteristics that determine its behavior during the race.

After each attempt:

1. The cars navigate the track.
2. The performance of each car is evaluated.
3. The best-performing cars are selected.
4. New cars are generated from the best individuals.
5. The process is repeated for multiple generations.
6. With each generation, the cars are expected to improve their ability to progress through the track.

The training process is performed on **3 different tracks**, and the best individual is then used in a final test.

## Technologies Used

* **JavaScript** — Genetic Algorithm, game logic, car movement, and training system.
* **HTML** — Structure of the application.
* **CSS** — Styling, layout, and visual presentation.
